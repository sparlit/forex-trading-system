# EAQTS V2.4 Documentation

This directory contains generated API reference docs for each engine.

- `event_bus/` – Event Bus API.
- `market_state_engine/` – Market State Engine API.
- `opportunity_engine/` – Opportunity Engine API.
- `portfolio_engine/` – Portfolio Engine API.
- `risk_engine/` – Risk Engine API.
- `safety_invariant_engine/` – Safety Invariant Engine API.
- `safety_kernel/` – Safety Kernel API.
- `trade_admission/` – Trade Admission API.
- `execution_core/` – Execution Core API.
- `position_manager/` – Position Manager API.
- `exit_engine/` – Exit Engine API.
- `learning_governance/` – Learning Governance API.
- `autonomy_model/` – Autonomy Model API.

Run `make docs` (future implementation) to generate HTML docs via `pdoc` or `mkdocs`.
